부업에 관심 있는 20~35세 직장인. "쿠팡 파트너스 해봤는데 안 됐다" 또는 "해보고 싶은데 어디서부터?"
하루 1~2시간 투자 가능, 초기 자본 0원 원하는 사람.
레이어 2 — 건드리는 감정 TOP 3
1. 의심 — "쿠팡 파트너스로 20억? 말이 되나?" (3번 실패 스토리가 더 강력)
2. 긴박감 — "AI로 쇼츠 만드는 거 아직 99%가 모른다면 지금 시작해야 하는 거 아냐?"
3. 동경 — "핸드폰 하나로 0원에서 20억이 가능하다면 나도?"
레이어 3 — 시청 이유 (진짜 욕구)
"쿠팡 파트너스 안 되는 이유"를 확인하려고 + 실제 방법을 알기 위해서.
"진짜 되는 사람은 어떻게 하는지" 내부자 정보가 궁금한 것.
레이어 4 — 채널의 암묵적 약속
"이 영상을 보면 핸드폰 하나로 쿠팡 파트너스 시작하는 구체적 방법을 알 수 있다."
+ "3번 망한 사람이 결국 해냈으니 나도 할 수 있다."
레이어 5 — 극복 장벽 (댓글 실측 기반)
1. "유익한데 어느 하나도 쉽진 않다" → 수강생 실제 수익 사례로 반박 (809좋아요 댓글)
2. "결국 이것도 강의 파는 거 아닌가요?" → 김정빈은 쿠팡 파트너스 자체로 20억 = 강의 의존 아님
3. "팔로워/알고리즘 바뀌면 끝 아님?" → 2년 생존 + 시스템화 자체가 반박 증거
댓글 분석 — 절약왕정약용 + 옆집CEO 실측
쿠팡 파트너스/부업 관련 채널 TOP 댓글 패턴 — 시청자 심리 직접 확인

썸네일 전략 — 3채널 교차 분석 기반

핵심: 핸드폰(저렴) vs 20억(고가) = 한 프레임 갭

핵심: "일하는 대표" 현장감
