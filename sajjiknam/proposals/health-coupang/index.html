조명 — 자택 인터뷰용 (자연광 보조)
보조 배터리/충전기 — 하루 종일 촬영
메모리 카드 여유분
3 반드시 찍어야 할 B-Roll
필수 나래휴게소 벤치에 앉은 뒷모습 (썸네일 A안)
필수 쿠팡 셀러 대시보드 매출 화면 (숫자 보이게)
필수 홈쇼핑 방송 화면 + 실시간 주문 알림 (16:35)
필수 자택 바다뷰 전경 (드론 또는 와이드)
노트북 앞에서 작업하는 출연자 (옆모습/뒷모습)
건기식 제품 박스/포장 클로즈업
출연자 일상 (커피 마시기, 산책 등)
나래휴게소 주변 풍경 (새벽 느낌 연출)
수강생과 대화하는 장면 (동석 시)
4 촬영 중 주의사항
① 감정 관리: 여자친구 사망/공황장애 이야기할 때 출연자 감정 존중. 무리하게 파지 않기.
② 쿠팡 화면: 개인정보(고객명, 주소) 가리기. 매출 수치만 보이게.
③ 홈쇼핑 타이밍: 16:35 전에 반드시 자택 도착. 카메라 세팅 완료 상태로 대기.
④ 수강생 개인정보: 1.7억 사기 이야기 → 본인 동의 필수. 얼굴 모자이크 여부 확인.
⑤ 출연자 스케줄: 디지털노마드라 시간 유연하지만, 홈쇼핑 시간은 고정.
편집팀 전달사항:
- 사찍남 25분: ACT 4(코로나 파산) 구간에 감성 BGM 전환 + 나래휴게소 B-Roll 삽입
- 부업소개 10분: 쿠팡 전략 설명 시 화면분할 (출연자 + 쿠팡 대시보드)
- 홈쇼핑 실시간 장면: PIP(Picture-in-Picture)로 TV화면 + 주문 알림 동시 표시
- 첫 5초: "직원 1,500명" 또는 "빚 7억" 자막 크게 + 1초 단위 컷전환
