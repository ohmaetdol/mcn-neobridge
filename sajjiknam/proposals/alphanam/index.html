질문 설계 원칙 — 데이터 근거
1. 타임라인 매핑: 각 질문이 10분 타임라인 어디에 배치되는지 표시. 피크(5~7분) 질문은 반드시 화면 공유를 유도하는 질문.
2. 리텐션 법칙 적용: 20개 영상 중 18개에서 "사이트 화면 공유 순간" = 최고 피크. 질문이 화면을 열게 만들어야 함.
3. 댓글 데이터 반영: 절약왕 1위 댓글(809좋아요) "어느 하나도 쉽진 않다" + 옆집CEO 댓글 40%가 실행 방법 질문 → "쉽다/할 수 있다"를 반복 추출하는 질문 설계.
4. 옆집CEO 콜라보 갭: 31분 콜라보에서 빠진 내용(첫 수익 과정, 논란, 실패 사례)을 이 30개 질문으로 채움.
5. 월 수익 프레이밍: 시청자는 "50억"이 아니라 "나도 월 100만원 가능한가"에 관심. 질문마다 월 단위 수익을 추출.
0~1분 | 오프닝 훅 — 초반 이탈 방지
데이터 알파남 콜라보 초반30초 리텐션 = 0.05 (100명 중 5명만 남음). 숫자 훅이 없었기 때문.
데이터 옆집CEO "월100 더 벌기" 영상만 초반30초 = 0.35 — 이유: 바로 방법론 진입.
목표 첫 질문에서 월 수익 숫자를 뽑아내야 시청자가 남는다.
Q1
훅 단도직입적으로요. 지금 블로그로 한 달에 실수령 얼마 들어와요?
목적: 첫 문장에 월 수익 숫자 추출. 시청자 이탈 방지의 핵심. "월 200만원이요" 같은 답이 나와야 한다.
Q2
갭 운전기사 할 때 월급이 250만원이었다면서요? 그때 블로그 왜 시작했어요?
목적: "월급 250만원 → 블로그 월 200만원+" 갭 형성. 절약왕 "퇴근후 부업" 210만뷰 제목의 핵심 구조.
Q3
시작 처음 시작했을 때 첫 달에 얼마 벌었어요? 진짜 첫 달이요.
목적: "첫 달 300만원" 추출. 시청자 기대치 세팅 — "나도 첫 달에 뭐라도 벌 수 있겠다."
1~3분 | 왜 블로그인가 — 정보 전달
데이터 절약왕 6분 미만 영상 킬러 비율 = 8.3%. 짧고 핵심만 전달할 때 리텐션 최고.
댓글 절약왕 1위(809좋아요) "어느 하나도 쉽진 않다" → 쉽다는 느낌을 주는 질문 배치.
목표 "블로그 = 노트북 하나로 월세 버는 부업"이라는 프레임 완성.
Q4

목적: 애드센스 구조를 30초 안에 설명. 절약왕 댓글 "쉽진 않다" 선제 차단. 어머니(60대) 사례 자연 연결.
Q5
실행 하루에 블로그에 쓰는 시간이 얼마나 돼요? 퇴근하고 할 수 있는 수준이에요?
목적: "하루 1시간" 추출 → 제목 공식A "하루 X시간 + 월 Y만원" (평균 79만뷰) 콘텐츠 근거.
Q6
장벽 초기 비용이 얼마나 들어요? 장비나 프로그램 사야 해요?
목적: "0원, 노트북만" 추출. 옆집CEO 댓글 40%가 초기 비용/장벽 질문 — 이 구간에서 미리 해소.
Q7
실행 티스토리, 워드프레스, 네이버 블로그 — 초보자는 뭘로 시작해야 해요?
목적: 선택지 단순화. 알파남 본인 채널 TOP1 영상(53K뷰)도 "티스토리 애드센스" 주제 — 시청자 관심 확인됨.
Q8
장벽 글을 잘 못 써요. 솔직히 맞춤법도 자신 없는데 가능해요?
목적: 절약왕 댓글 "쉽진 않다" 직접 대응. "60대 어머니도 하고 있다" 답변 유도 → 장벽 파괴.
