1 15분 영상 구성
핵심 앵글
건강식품 = "욕구 시장" (절대 안 죽는 시장)
남성의 성욕, 여성의 미용 욕구, 노인의 건강 불안 — 인간의 본능적 욕구를 건드리는 시장.
재구매율 높고, 목적성 구매라 키워드만 잡으면 바로 돈이 된다.
다른 건강식품 강사에게 없는 프레임.
설계 근거: 절약왕+옆집CEO 20개 히트맵 분석 → 킬러구간 7~8분(51%), 화면공유=피크, 초반30초 약함(0.02~0.19) → AI 화면 오프닝 + 5~8분 풀시연 + 8~10분 매출공개
타임라인 — 사무실 원컷
0~1분
임팩트 오프닝 훅
AI 프로그램 화면 먼저 보여주기. "1분이면 끝납니다" → 건강식품 하나 소싱 완료 시연
1~3분
자기소개 + 편의점 시절 과거
CU 영업관리직 → 통장 150만원 → 폐기 도시락 3개월. "그때 편의점 건강식품 떼다 팔기 시작"
3~5분
"욕구 시장" 이론 핵심
왜 건강식품인가. 발기 영양제, 빈뇨, 탈모 — 남 못 할 고민을 해결하는 시장. 재구매 + 목적성 구매
5~8분
AI 프로그램 풀 시연 핵심
질병 선택 → 원료 추천 → 도매몰 연동 → 썸네일 AI 생성 → 상품명 자동 → 전체 1분 완료
8~10분
수익 구조 공개 수치
실제 매출 화면 공개. "직원 0명으로 월 4~5억". 위탁 vs 제조 단계별 설명
10~12분
수강생 실제 사례 증거
2월 시작 → 1달 만에 월 7천만원. 누적 수강생 1,000명+, 억대 매출자 다수
12~14분
과거 회고 + 마무리 감성
"5년 동안 배운 걸 AI로 만들어놨으니까, 시작하시는 분들은 저처럼 고생 안 해도 돼요"
14~15분
CTA 전환
무료 특강 5/11 안내 + "진짜 하실 분만 오세요" + 사찍남 롱폼 링크
2 오프닝 스크립트
사무실 — 임팩트 시작 (AI 화면 먼저)
[0초] 사무실. 노트북 화면 클로즈업 — AI 프로그램 켜져 있는 상태 [3초] "건강식품 하나 소싱하는 데 1분이면 끝납니다." [5초] 질병 선택 클릭 → 원료 추천 뜸 → 도매몰 가격 표시 [10초] "이거 온라인에 올리면 마진 5배예요." [15초] 백종환 얼굴 전환 "오늘 이 구조 전부 보여드릴게요."
과거 이야기 — 편의점 시절 회고
[1분~] "저 원래 CU 편의점 영업관리직이었거든요. 통장에 150만원밖에 없었고, 폐기 난 불고기 도시락 3개월 동안 매일 먹었어요. 그때 편의점에 들어오는 건강식품 싸게 사서 온라인에 올렸어요. 그게 시작이었어요. 한 달에 7, 80만원씩 벌었죠."
AI 시연 도입
[5분~] "근데 이렇게 하나하나 찾고, 사진 찍고, 상품명 짓고 하면 시간이 너무 걸려요. 그래서 제가 만들었습니다." 노트북 화면 전환, AI 프로그램 풀 시연 "이거 1분이면 다 끝나요. 제대로 보여드릴게요."
