22권 핵심 프레임워크 (에이전시 두뇌)

StoryBrand SB7 — 영상 구조

모든 영상은 이 구조를 따른다:
주인공(출연자) → 문제(돈/생존) → 가이드(사찍남) → 계획(방법론) → 행동촉구 → 성공 → 실패 회피

Hook-Story-Offer — 제목/영상/엔딩

Hook = 제목+썸네일 (5초 내 어그로)
Story = 영상 본편 (Epiphany Bridge)
Offer = 엔딩 CTA (다음 영상/구독)

Value Equation — 콘텐츠 가치

꿈 결과(Dream Outcome) × 성공 확률(Perceived Likelihood)
÷ 시간 지연(Time Delay) ÷ 노력과 희생(Effort & Sacrifice)
→ 분자↑ 분모↓ = 시청 가치 극대화

LF8 심리 트리거 — 썸네일/제목

  • #3 공포 회피 → 실패/빚 스토리
  • #5 편안한 생활 → 돈다발/수익 공개
  • #6 우월감 → 놀란 표정 + 큰 숫자

Epiphany Bridge — 깨달음의 순간

출연자가 인생을 바꾼 '깨달음의 순간'을 7~10분에 배치.
"그때 깨달았어요" = 킬러 구간의 핵심.
감정적 각성(backstory) → 외적 여정(방법) → 내적 깨달음(교훈)

3 False Beliefs — 믿음 파괴

시청자의 잘못된 믿음 3개를 영상으로 파괴:
1) 수단 (Vehicle) — "이 방법이 안 될 거야"
2) 내적 (Internal) — "나는 못 할 거야"
3) 외적 (External) — "환경이 안 돼"

Ad Kaleidoscope — 제목 테스트

같은 소재를 2~3가지 앵글로 제목 변주.
Who(누구) × What(무엇) × Why(왜) × How(어떻게)
→ 업로드 후 24시간 A/B 테스트

Grand Slam Offer — 제안의 힘

콘텐츠 자체가 "거부할 수 없는 제안"이 되게.
출연자의 무료 강의/전자책 → Dream 100 트래픽.
영상 = 무료 가치, 댓글 = 사회적 증거

레퍼런스 벤치마크 인사이트

돈탐생 공식

오프닝 숫자자극 → 7~10분 수익공개(63% 집중) → 16분 마무리. 교차편집 속도감.

휴먼스토리 공식

감정 몰입 오프닝 → 전반부 감동 → 29분 긴 호흡. BGM+여유컷으로 완주율.

사찍남 하이브리드 목표

돈탐생 오프닝(숫자자극) + 사찍남 중반(인터뷰) + 휴먼스토리 후반(감성) = 18분.

킬러 구간 설계

조회수와 리텐션 상관계수 ~0 → CTR/제목이 조회수 결정. 리텐션은 완주율에 영향.
