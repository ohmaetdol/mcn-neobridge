편집 기획서 작성 가이드
오프닝 (0~30초) — 승패가 결정되는 구간
- 첫 3초: 가장 강한 씬/멘트로 시작 (시청자 50~60%가 여기서 이탈)
- 15초 내: "이 영상을 왜 봐야 하는지" 설득 완료
- 25~35초: 패턴 인터럽트 (앵글 전환, 효과음, 자막 강조)
→ 처음 30초에서 70% 유지하면 알고리즘이 추천 시작
본편 — 컷 리듬이 핵심
- 15~25초마다 시각 변화 (B-roll, 줌컷, 자막, 효과음)
- 2~3분마다 "버스트 시퀀스" (빠른 컷 5~10개) → 다시 안정
- 킬러 씬은 7~10분 사이에 집중 배치 (사찍남 데이터: 뒤로 밀리면 리텐션 하락)
- 6~12분 구간은 "안전지대" — 이탈률이 거의 없음
자막 효과 (데이터)
- 자막 있는 영상: 91%가 끝까지 시청 (없으면 66%)
- 조회수 12~13% 상승, 모바일에서 효과 더 큼
BGM 볼륨 기준
- 차분한 구간: 목소리 대비 -20~-25dB
- 에너지 구간: 목소리 대비 -8~-12dB
- 템포: 설명/교육 60~80 BPM / 빌드업/하이라이트 100~120 BPM

8분 이상 시청 시 알고리즘 부스트 / 6~12분 구간은 이탈률 최저
