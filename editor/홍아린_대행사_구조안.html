FLOWMUS

Core Structure

01
편집만 하면 단가 경쟁. 기획이 붙어야 가치가 올라간다.
기획 없는 편집 = 단순 노동, 단가 하락 / 기획 있는 편집 = 성과가 나오는 영상, RS가 가능한 구조
사업 개요
사업기획 + 편집 대행사 (브랜드명 미정 -- 미팅에서 확정)
운영 주체Flowmus + 홍아린 공동 운영
홍아린대행사 대표/총괄 (콘텐츠 디렉팅, 편집팀 관리, 클라이언트 관리)
Flowmus데이터/AI 기반 기획, 커머스 설계, 시스템/인프라, 클라이언트 유입
편집팀홍아린 기존 보유 팀 (건당 고정급)
전체 흐름: 기획 + 편집 + 커머스
콘텐츠 기획 Flowmus + 홍아린
→
커머스 기획 상품/동선 설계
→
촬영 가이드 클라이언트 전달
→
편집 홍아린 편집팀
→
납품 + RS 매출 추적/정산
서비스 라인 2개
LINE 1

숏폼 기획 + 편집 + 커머스 RS

  • 타겟: 소상공인, 인플루언서
  • 기획: 콘텐츠 기획 + 커머스 기획
  • 편집: 릴스/숏츠/틱톡 15~60초
  • 수익: 편집비 저단가 + 커머스 매출 RS
기획이 붙으니까 영상이 "팔린다" = RS 가능
LINE 2

AI 기업 광고 기획 + 제작 + 강의

  • 타겟: 기업 (중소기업, 스타트업, 브랜드)
  • 기획: 광고 콘셉트/타겟/메시지 설계
  • 제작: AI 소재 대량 생산
  • 수익: 광고 대행료 + 강의비
광고 예산에서 집행 = 고단가 마진

LINE 1: 숏폼 기획 + 커머스 RS

02
왜 기획이 필요한가?

편집만 대행

  • 클라이언트가 보내는 대로 편집
  • 영상 퀄리티 들쭉날쭉
  • 조회수/매출 보장 불가
  • 커머스 RS 붙일 명분 없음
단가 경쟁 → 바닥

기획 + 편집 + 커머스

  • 뭘 찍을지/어떻게 팔지까지 설계
  • "팔리는 영상" 기획 → 성과 보장
  • 성과가 나니까 RS 정당화
  • 올인원 → 클라이언트 가치 높음
기획 = RS의 근거
기획 범위
콘텐츠 기획

뭘 찍을지, 어떻게 찍을지

  • 트렌드 분석 → 뜨는 포맷/주제 선정
  • 클라이언트 업종별 콘텐츠 전략
  • 영상별 훅/구성/스크립트 방향
  • 월간 콘텐츠 캘린더
Flowmus 데이터 + 홍아린 디렉팅
커머스 기획

어떤 상품을, 어떻게 팔지

  • 클라이언트 상품 분석 → 주력 상품 선정
  • 스마트스토어/자사몰 연동 설계
  • 영상 → 구매 전환 동선 (CTA, 링크 배치)
  • UTM/전용 링크 세팅 → 매출 추적
Flowmus 커머스 설계
숏폼 커머스 RS 전체 흐름
콘텐츠 기획 주제/훅/구성
→
커머스 기획 상품/동선/링크
→
촬영 가이드 클라이언트 촬영
→
편집 + QC 홍아린 팀
→
RS 정산 스토어 매출 추적

혼합형만원대/월매출 __%콘텐츠 + 커머스 기획

LINE 2: AI 기업 광고 + 강의

03
기업은 "편집비"에는 인색하지만 "광고비"에는 예산이 있다. AI로 원가 낮추고, 광고 단가로 청구 = 마진 극대화.
2-A. AI 광고 영상 제작 대행
타겟기업 (중소기업, 스타트업, 브랜드)
기획광고 콘셉트 기획 → 타겟/메시지/소재 방향 설계 (Flowmus AI + 홍아린)
제작AI 소재 생성 → 편집 → 플랫폼별 리사이징 → 납품
광고 유형SNS 광고 (메타/인스타), 유튜브 광고, 네이버/카카오 DA, 숏폼 광고
핵심 가치1개 촬영본에서 AI로 10~20개 광고 소재 변형 생산
패키지내용월 가격(안)비고
스타터광고 소재 5편/월만원대SNS 광고 기본
그로스광고 소재 15편/월 + A/B 변형만원대멀티 플랫폼
스케일광고 소재 30편+/월 + 성과 리포트별도 협의전담 운영
2-B. 기업 AI 강의 (업셀)
형태기업 출강 / 워크숍 / 사내교육
강사홍아린
주제AI 활용 광고 소재 제작, AI 마케팅 도구 실습
포지셔닝"광고 대행도 맡기고, 사내 마케팅팀 AI 역량도 키우세요"
형태시간가격(안)비고
단발 특강2~3시간만원대1회성 기업 출강
워크숍반일~1일만원대실습 포함 심화
정기 교육월 2~4회월 만원대사내 마케팅팀 양성
광고 → 강의 연결
AI 광고 대행 계약 기업 확보
→
광고 성과 신뢰 결과물로 증명
→
강의 제안 "사내팀도 배워보세요"
→
이중 수익 광고 + 강의
