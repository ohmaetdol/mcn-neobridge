서윤님 실제 릴스 발화 (reel #26)

서윤님이 적합한 4가지 이유

1. 이미 사주 콘텐츠 업로드 경험 — 팔로워가 거부감 없음
2. 평소 광고 패턴과 100% 일치 — "써봤는데 진짜 좋더라" 구조
3. 30-40대 여성 = 사주/운세 핵심 결제 타겟
4. "30만원 vs 전화 한 통" 비교 구도가 자연스러움

콘텐츠 기획 실제 전화 통화 리액션형 30-45초
"남편 사주 전화로 물어봤는데 선생님이 소름 돋는 말을 하신다"

첫 3초 후킹

"남편 몰래 사주 선생님한테 전화했는데..."

영상 구성 (실제 전화 통화 촬영)

0-5초
도입 — 카메라에 속삭이듯
"여러분 나 지금 남편 몰래 사주 선생님한테 전화할 거야. 우리 궁합이랑 남편 얘기 물어볼 건데..."
소파에서 몰래 하는 느낌. 남편 안 보는 타이밍.
5-8초
전화 거는 장면
(폰에 전화 거는 화면) "여보세요~ 선생님 안녕하세요!"
실제 박명화 선생님과 전화 연결되는 장면. 스피커폰.
8-25초
실제 통화 + 리액션 (핵심 장면)
박명화 선생님이 남편 사주/궁합에 대해 말씀하시는 걸 듣고 리액션하는 서윤님. 통화 내용 중 소름 돋는 부분에서 카메라 보며 놀라는 표정.
리액션 예시: "아... 맞아 진짜로?" / "어떻게 아세요 그걸?" / "헐 소름..."
선생님 음성은 스피커폰으로 들리거나, 서윤님이 들은 내용을 바로 카메라에 전달해도 OK. 진짜 놀라는 자연스러운 리액션이 핵심.
25-35초
통화 끝 + 감상 + CTA
"아 진짜 소름이야... 내가 말 안 했는데 남편 성격을 그대로 맞추시네. 여러분 이거 100원에 텍스트 사주 먼저 보고 전화 상담받는 건데, 진짜 한번 해봐. 궁금하면 댓글 남겨!"
통화 끝나고 흥분된 상태로 카메라에 감상 전달. 자연스러운 마무리.
텍스트: "댓글 남기면 링크 전달"

이 구성이 터지는 이유

"실제 전화 통화 장면" = 서비스 체험을 눈으로 보여준다

- 설명이 아니라 실제 통화 → 시청자가 간접 체험
- 리액션이 자연스러울수록 신뢰도 상승
- "나도 전화해보고 싶다" → 전환 욕구 극대화
- 남편 소재 = 기혼 여성 공감 + 궁금증

촬영 가이드
