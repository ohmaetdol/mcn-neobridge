결정사 첫 만남,
상대는 7분 안에 결정합니다

EP.04 · 듀얼 로케이션 (카페 + 스튜디오) · 첫 만남 해부형

12~14분 야외 카페 + 스튜디오 아는언니 리지

이 영상은 뭔가요?

결정사 첫 만남에서 상대가 7분 안에 판단하는 기준 TOP 5를 공개하고, 본인도 첫 만남에서 실패한 경험을 솔직하게 고백하는 영상입니다.

EP03에서 "프로필"을 다뤘으니, 이번엔 "첫 만남" — 프로필 통과 후 실제 만남에서 어떻게 판단되는지를 보여줍니다.

촬영 포맷

듀얼 로케이션 — 야외 카페(40%)에서 현장감 있는 토크 + 스튜디오(60%)에서 데이터·분석.

대본 없습니다. 키워드만 숙지하시면 됩니다.

촬영 시간: 약 3시간 (카페 → 스튜디오 이동 포함)

핵심 원칙: 아래 커뮤니티 이슈를 촬영 전에 한 번 읽어주세요.
"아 요즘 이런 게 화제구나" 정도만 머릿속에 넣으면 됩니다.
PD가 이 자료를 기반으로 질문합니다. 대표님은 아는 만큼, 느끼는 만큼 솔직하게 답변하면 됩니다.
카페에서 커피 주문하면서 시작합니다. 인사 없이 바로.

우리 채널의 반복 포맷

모든 에피소드는 같은 흐름으로 진행됩니다. 외울 필요 없고, "이런 흐름이구나" 정도만 알면 됩니다.

매 에피소드 5단 구조

[킥] 주제 관련 뭔가 들고 바로 시작. 인사 X. (0~30초)

[해부] 업계가 이렇게 돌아감. 이세령 = 인사이더. (약 5분)

[본인] "그래서 나는?" 본인에게 적용. 자학+솔직. (약 4분)

[반전] "근데 진짜 중요한 건..." 메시지. (약 3분)

[아웃] 캐치프레이즈 + 여운 + 페이드아웃. (약 1.5분)

자연스럽게 나올 캐치프레이즈

아래 문장들은 외워서 읽는 게 아니라, 대화 중에 자연스럽게 나오면 좋은 표현입니다.

해부 블록에서
"결정사 안에서 보면요"
첫 만남 탈락 사유를 설명할 때 — "업계 사람만 아는" 뉘앙스
본인 블록에서
"겪어봐야 아는 거예요"
본인 첫 만남 실패 경험을 이야기할 때
반전 블록에서
"첫인상이 다가 아니에요"
메시지 전달할 때 — 이 영상의 핵심 한 줄
이 표현들을 암기하지 마세요

PD가 질문 흐름을 이끌어서 자연스럽게 이 표현이 나오도록 유도합니다. 대표님은 편하게 대화하시면 됩니다.

촬영 전 읽을 자료

아래는 요즘 결정사 첫 만남/미팅 관련 커뮤니티에서 화제가 되고 있는 내용입니다. 촬영 전에 한 번 읽고 "아 이런 게 있구나" 정도만 파악해두세요.

1. "밥값 누가 내야 하나" (블라인드/에펨코리아)

"결정사 첫 만남에서 남자가 다 내야 한다" vs "각자 내야 한다" 논쟁이 반복적으로 화제. 결정사 회원들도 후기에서 가장 많이 언급하는 이슈.

2. "핸드폰만 보는 사람" (네이트판/블라인드)

"첫 만남인데 핸드폰만 봐서 5분 만에 나왔다" 후기 다수. 결정사 매칭 거절 사유 상위권.

3. "프사랑 실물이 너무 다르다" — EP03 연결

EP03에서 다뤘던 "프사기"가 실제 만남에서 터지는 순간. "만나자마자 5분 만에 끝난 미팅" 후기가 계속 올라옴.

4. "질문을 안 해요" (레딧/블라인드)

"상대가 나한테 질문을 하나도 안 했다" = "관심 없다는 시그널"이라는 분석 게시물이 공감 폭발.

5. "인터뷰 당하는 느낌" (네이트판)

"본인 이야기만 30분 했다" "나는 듣기만 했다" — 대화 독점이 첫 만남 최악의 실수라는 글.

이 자료를 외울 필요는 없습니다

"아 요즘 이런 게 화제구나" 정도만 머릿속에 넣으면 됩니다. PD가 촬영 때 이 내용을 질문으로 물어봅니다. 모르는 건 "모르겠는데요?"로 OK.

촬영 흐름

PD가 질문 15개로 흐름을 이끕니다. 대표님은 자연스럽게 답변만 하면 됩니다. 이번에는 카페와 스튜디오 두 곳에서 촬영합니다.

  • [킥] 0~30초 — 카페
    카페에서 커피를 받으면서 바로 시작.
    "7분. 첫 만남에서 상대를 판단하는 데 걸리는 평균 시간이에요."
    인사 없이 바로. 커피 주문 후 자연스럽게.
  • [해부] 약 5분 — 스튜디오 — "결정사 안에서 보면요"
    첫 만남 탈락 사유 TOP 5를 5위부터 1위까지 카운트다운.
    PD가 "5위부터 가볼까요?" "그러면 4위는?" 식으로 물어봅니다.
    실제 첫 만남 피드백 데이터를 기반으로 자연스럽게 설명.
  • [본인] 약 4분 — 카페→스튜디오 — "겪어봐야 아는 거예요"
    PD가 "대표님은요? 첫 만남에서 실패한 적?" 물어봅니다.
    본인도 첫 만남에서 실패한 경험을 솔직하게.
    tvN 맞선 에피소드 콜백, 회원 피드백 패턴도 자연스럽게.
  • [반전] 약 3분 — 스튜디오 — "첫인상이 다가 아니에요"
    "그러면 어떡해요?" 질문에 솔루션 3가지 제시.
    "첫인상이 다가 아니에요. 3번째 만남에서 역전된 커플이 있어요."
  • [아웃] 약 1.5분 — 카페
    카페를 나가면서 마무리. "첫 만남이 두려운 사람한테 한마디?"
    대본 없이 마음에서 우러나오는 말. PD가 10초+ 기다려줍니다.

촬영 전 준비할 것

1
첫 만남 탈락 TOP 5 실제 사례
회원들의 첫 만남 후 피드백에서 "이 사람은 다시 안 만나겠다"는 사례를 머릿속에 5개 정도 준비. 구체적일수록 좋습니다. (회원 정보는 당연히 익명 처리)
2
본인 첫 만남 실패담
결정사/소개팅/맞선에서 첫 만남이 망한 적 있는지, 본인이 실수한 적 있는지 떠올려두세요. tvN 맞선 에피소드도 좋습니다.
3
"7분 안에 합격하는 사람"의 공통점
결정사 데이터 기반으로 "첫 만남에서 2차 성사되는 사람"의 패턴을 정리해두세요. (예: 질문을 잘 한다, 리액션이 좋다, 시선 처리 등)
4
3번째 만남에서 역전된 실화
첫인상은 별로였는데 2~3번째 만남에서 역전해서 성사된 실제 커플 사례가 있으면 준비. 반전 블록에서 가장 중요한 스토리입니다.

PD 질문 방식 안내

위에서 읽은 커뮤니티 이슈를 PD가 질문 15개로 만들어서 물어봅니다.

예를 들어 PD가 "요즘 블라인드에서 '밥값 논란'이 있던데, 결정사 첫 만남에서 밥값은 어떻게 해요?" 라고 물으면,
대표님은 맥락을 알고 있는 상태에서 "실제로 저희 회원 중에 밥값 때문에..." 식으로 본인 경험을 자연스럽게 풀면 됩니다.

TOP 5 카운트다운 순서는 PD가 이끕니다. 대표님은 각 순위에 대해 편하게 이야기하시면 됩니다.
PD의 고정 질문 패턴 4개

PD는 아래 4가지 패턴으로 질문합니다. 대표님은 자연스럽게 답하면 됩니다.

"진짜요?" — 충격 데이터가 나왔을 때. (매칭 거절률 89% 등)

"그건 좀 불공평하지 않아요?" — 밥값/외모 불일치 등 시청자 입장 반론.

"대표님은요?" — 업계 이야기에서 본인 이야기로 전환할 때.

"그러면 어떡해요?" — 솔루션/메시지로 유도할 때.

톤 가이드

이렇게 말해주세요

업계 인사이더의 솔직함 — "실제로 첫 만남 후 피드백에서 가장 많이 나오는 게..." "저희 데이터로 보면..."

자학 유머 — "저도 그랬어요" "tvN에서 5번 만났는데 진짜 질문을 못 했어요"

구체적 데이터 — "핸드폰 확인한 사람의 매칭 거절률 89%" 같은 숫자

분석은 OK, 판단은 NO — "거절 사유"는 설명, "당연하다"는 X

이렇게 말하지 마세요

"이런 사람은 당연히 탈락이죠" — 판단/비하 X

"남자가 나빠" / "여자가 문제" — 성별 편들기 X

"우리 채널 구독해주세요" — 영상 내 구독 유도 0회

첫 만남을 "시험" "테스트"로 프레이밍 — 만남을 평가로 만들지 X

절대 하지 말 것

절대 금지

1. "안녕하세요" 인사 — 커피 주문하면서 바로 시작

2. "구독/좋아요" 멘트 — 영상 내 0회

3. 경쟁사 실명 (듀오, 가연, 엔노블, 제이노블) → "메이저 결정사"로만

4. 특정 회원 정보 → "어떤 분이~" 익명 처리

5. EP01~03 스토리 반복 — 인생서사/등급/프로필 다시 X

주의

MCN/네오브릿지 언급 X → 순수 개인 채널

워터밤 / 황정우·이나영 사건 → 절대 금지

본인 결정사 가격 직접 공개 → "업계 평균"으로만

특정 성별 비하 → 중립. "남자가 나빠" "여자가 문제" X

첫 만남을 "시험"으로 프레이밍 → 만남이지 테스트 X

동의 확인

아래 항목을 촬영 전에 확인해주세요.

  • 첫 만남 탈락 TOP 5 공개 — 실제 첫 만남 탈락 사유를 카메라 앞에서 설명하는 것에 동의
  • 본인 첫 만남 실패담 공개 — 본인도 첫 만남에서 실패한 경험을 말하는 것에 동의
  • 커뮤니티 이슈 답변 — PD가 물어보는 최근 화제(밥값 논란, 핸드폰 등)에 답변하는 것에 동의
  • 실화 언급 — 익명 처리 조건으로 실제 회원 첫 만남 사례를 이야기하는 것에 동의
  • tvN 맞선 콜백 — 본인 tvN 출연 경험을 언급하는 것에 동의
  • 엔딩 — 대본 없이 마지막 메시지를 자유 발언하는 것에 동의
