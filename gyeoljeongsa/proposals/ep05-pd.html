절대 금지 5개

1. "안녕하세요" 인사 — "연봉 1억 2천"으로 바로 시작

2. "구독/좋아요" 멘트 — 영상 내 0회

3. 경쟁사 실명 — "메이저 결정사" "업계"로만

4. 특정 회원 실명/정보 — 가명 + 익명 처리

5. "결정사는 사기다" 류의 표현 — 한계 인정이지, 전면 부정이 아님

주의 5개

1. 외부 관계 언급 X → 순수 개인 채널

2. 워터밤 / 황정우·이나영 사건 → 절대 금지

3. 본인 결정사 가격 직접 공개 → "업계 평균"으로만

4. 특정 성별 비하 → 중립. "남자가 나빠" "여자가 문제" X

5. 이혼을 부정적으로만 프레이밍 → "잘못된 결합을 끝내는 용기"도 존중
