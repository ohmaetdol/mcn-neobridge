의사랑 결혼하는 법

628만뷰 의사남편 브이로그 팩트체크 — 양면 제시형
호스트
이세령 (결정사 대표)
런타임
13~15분
콘셉트
팩트체크 + 양면 제시
캐치프레이즈
"의사가 다가 아닙니다"

PD 고정 패턴

4가지 패턴 반복

"진짜요?" — 놀람/확인

"그건 좀 불공평하지 않아요?" — 대리 반론

"대표님은요?" — 자학 전환

"그러면 어떡해요?" — 해결책 유도

톤 전환 4단계

Q1~Q4: 밝은 톤 (정보 전달, "가능해요")

Q5~Q8: 솔직한 톤 (업계 비밀, "근데요...")

Q9~Q12: 진지한 톤 (안타까움, 작은 목소리)

Q13~Q15: 따뜻한 톤 (희망, 미소, 진심)

[킥] 오프닝

0:00 ~ 0:30
PEAK Q1
"628만명이 봤습니다. 의사남편 브이로그."
화면에 실제 브이로그 썸네일 띄우기. 숫자 하나마다 끊기: 한강뷰 / 명품 / 연봉 25억. "오늘 결정사 대표인 제가 팩트체크 하겠습니다." 자신감 톤, 카메라 정면.
PD Q2
"팩트체크요? 의사남편 브이로그를요?"
답변 기다리기. 짧으면 "진짜요?" 추가. "가능한지 불가능한지, 결혼 '후' 이야기까지" 받기.

[해부] 방법론 + 업계 비밀

0:30 ~ 6:00
DATA Q3
"의사를 만나려면 어떻게 해야 해요? 현실적인 루트가 있어요?"
밝은 톤. 3가지 루트 나열 (결정사/학회·세미나/의대 동문 인맥). 자막: 루트 리스트 그래픽 삽입.
PD Q4
"결정사에서는 의사 만나기 쉬워요?"
긍정 답변 예상. 꼬리질문 준비: "성공률은요?" / "많이 오세요?"
PEAK Q5
"근데 업계에서 의사 회원 가입비가 무료라면서요?"
핵심 장면. "미끼거든요" 발언. 톤 전환 시작. 답변 후 정적 2초. 꼬리질문: "업계 전체가 그래요?"
Q6
"그러면 의사라고 다 인기 있는 거예요?"
"아닙니다" — 완전 전환 포인트. 꼬리질문: "어떤 의사가 인기 없어요?"
PEAK Q7
"자산 50억 치과의사도 퇴짜 맞았다고요?"
커플팰리스 스토리텔링 유도. 프로필 → 줄 섬 → 얼굴 공개 → 철회. 놀란 표정 재현. "외모가 새로운 자산이 된 시대."
PD Q8
"키 170 미만이면 수억 있어도 매칭 안 된다고요?"
꼬리질문: "그건 좀 불공평하지 않아요?" (대리 반론 패턴)

[실화] 결혼 후 현실

6:00 ~ 10:00
PD Q9
"결혼 '후'는요? 브이로그처럼 좋은 거 아니에요?"
전환 순간. "여기서부터 진짜 이야기입니다" 유도. 톤 진지하게.
TREND Q10
"네이트판에 49만명이 본 글 있잖아요. 10억 투자했는데 6개월 만에..."
스토리텔링 유도. 안타까운 톤. 빠르게 말하지 않기. 꼬리질문: "이거 특수한 경우예요?"
PEAK Q11
"의사 배우자들이 가장 힘든 게 뭐예요?"
클로즈업. 리테이크 금지. 4가지 나열 기다리기 (당직/시댁/대출/외로움). 작은 목소리 구간. 선택지 제시 금지.
PD Q12
"대표님 회원 중에도 그런 분 있어요?"
가명 처리 확인. 캐치프레이즈 타이밍: "브이로그에는 안 나오는 이야기예요." 꼬리질문: "지금은 어떠세요?"

[반전] 결혼을 잘 하는 법

10:00 ~ 13:00 · 의사 이야기 → 결혼의 본질로 전환
PEAK Q13
"그러면 의사분들은 진짜 뭘 원해요? 어떤 배우자요?"
여기서 다시 밝아지기. 데이터 공개: 성격 55% > 외모 3%. 자막 강조. 그리고 전환 유도: "이건 의사만의 이야기가 아니에요. 행복한 결혼을 한 사람들 전부 같은 말을 합니다."
PEAK Q14
"그러면 결혼을 잘 하려면 뭘 봐야 하는 거예요?"
핵심 도달. 의사든 회사원이든 — 직업/조건이 아니라 성격, 가치관, 호환성. "의사가 다가 아닙니다. 직업을 보지 말고 사람을 보세요." 리테이크 절대 금지. 정적 3초. 이것이 "의사 결혼" 영상이 아니라 "결혼을 잘 하는 법" 영상이라는 것을 여기서 드러내기.

[아웃] 마무리

13:00 ~ 15:00
Q15
"지금 결혼하고 싶은 분들한테 한마디?"
"의사랑"이 아닌 "결혼" — 의도적 범위 확장. 정면 응시 3초. PD 컷 부르지 말 것. 5초 더 촬영. 열린 결말. CTA 없음.

Ban 리스트

절대 금지 5개

1. "안녕하세요" 인사 → 인사 없이 바로 시작

2. "구독/좋아요" 멘트 → 영상 내 0회

3. 경쟁사 실명 → "메이저 결정사" "업계"로만

4. 특정 회원 실명/정보 → 가명 + 익명 처리

5. "의사 브이로그 사기다" 류 표현 → 팩트체크이지 비방 아님

주의 5개

1. 외부 관계 언급 금지 → 순수 개인 채널

2. 의사남편 브이로그 당사자 비하/조롱 금지

3. 본인 결정사 가격 공개 금지 → "업계 평균"으로만

4. 특정 성별 비하 금지 → 중립 유지

5. 의사 직업 부정적 프레이밍만 금지 → "좋은 점도 있지만 현실도 있다"
