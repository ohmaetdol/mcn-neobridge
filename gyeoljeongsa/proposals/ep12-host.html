출연자용 EP.12 촬영 브리프 v1 · 2026.05.24

남자는 왜 결혼을 안 하는가

EP.12 · 스튜디오 PD 질문 토크 · 블라인드 9,201명 데이터 해부형

12~14분 스튜디오 아는언니 리지

이 영상은 뭔가요?

블라인드 직장인 22,095건 데이터로 남자들이 결혼을 안 하는(못 하는) 이유를 해부하는 영상입니다.

전반부에 "돈/감정/두려움"으로 현실을 직시시킨 후, 후반부에 "편한 사람"이라는 반전을 보여줍니다.

외부 데이터(블라인드)와 내부 데이터(결정사 성혼 커플)가 같은 결론에 도달하는 것이 핵심 장치입니다.

촬영 포맷

스튜디오 PD 질문 토크 — PD가 질문하면 대표님이 자연스럽게 답하는 형식입니다.

대본 없습니다. 키워드와 핵심 숫자만 숙지하시면 됩니다.

촬영 시간: 약 2시간

핵심 원칙: 아래 블라인드 글을 촬영 전에 한 번 읽어주세요.
"아 직장인들이 이런 고민을 하는구나" 정도만 머릿속에 넣으면 됩니다.
PD가 질문으로 이끌어가고, 대표님은 아는 만큼, 느끼는 만큼 솔직하게 대답하면 됩니다.
인사 없이 바로 시작합니다.

우리 채널의 반복 포맷

모든 에피소드는 같은 흐름으로 진행됩니다. 외울 필요 없고, "이런 흐름이구나" 정도만 알면 됩니다.

매 에피소드 4단 구조

[킥] 숫자로 바로 시작. 인사 X. (0~30초)

[해부] 왜 안 하는가 — 📎 한미연 2만건 분석 · 돈 53.6% / 감정 조건 / 두려움. (약 5분)

[반전] 언제 결심하는가 — 📎 블라인드 "결심하는 순간들" · 상담 경험 + "편한 사람" 반전. (약 5분)

[아웃] 몇 살까지 만나야 하는가 — 📎 블라인드 "나이별 소개팅 전략" · "33살" + 열린 결말. (약 2.5분)

캐치프레이즈는 촬영 당일 PD가 안내합니다

외울 필요 없습니다. PD가 촬영 흐름을 안내하면서 자연스럽게 나오도록 도와줍니다.

촬영 전 읽을 자료

아래는 이번 에피소드의 핵심 소스가 되는 블라인드 글과 데이터입니다. 촬영 전에 한 번 읽고 "아 이런 데이터가 있구나" 정도만 파악해두세요.

1. 한미연 분석 보고서 — 블라인드 22,095건 전수 분석 (세계일보/경향신문)

결혼 글 3년 새 3배 증가(9,201건). 결혼 감정 1위 = 두려움. 행복하다고 쓴 비율 9.3%. 부정 감정 매년 상승(46.3%→53.6%).

2. 블라인드 — "결혼적령기 남성들이 결혼 못하고 안 하는 이유"

"사랑이 결혼의 필수 조건이 된 시대에서 깊은 감정 없이는 결혼이 어렵다." 연봉은 숫자로 나오는데 사랑은 확인이 안 된다.

3. 블라인드 — "남자가 결혼을 결심하는 순간들"

결혼 결심 1위 = "편한 사람". 외모/돈/집안이 아니라 "긴장이 안 되는 사람."

4. 블라인드 — "나이별 소개팅 전략" (추천 96, 댓글 161)

"33살 안에 반드시 만나야 한다." "35세에 처음 만나는 것과 35세까지 사귀는 것은 본질적으로 다르다."

이 자료를 외울 필요는 없습니다

"아 블라인드에 이런 데이터가 있구나" 정도만 머릿속에 넣으면 됩니다. PD가 촬영 때 흐름을 안내합니다.

촬영 흐름

PD가 질문하면 대표님이 자연스럽게 답합니다. 외우지 않아도 됩니다.

  • [킥] 0~30초 — 인사 없이 바로 시작
    이렇게 시작합니다:
    "삼성, 현대, 카카오… 대기업 직장인들이 회사 인증하고 익명으로 글을 쓰는 곳이 있어요. 블라인드."
    → "거기에 결혼 고민 글이 올라옵니다."
    → "2023년. 3,073개." → "2024년. 4,267개." → "2025년. 9,201개." → "3년 새 3배가 됐어요."
    숫자를 또박또박, 천천히 끊어 읽어주세요. 카메라 정면.

    PD가 물어봅니다: "가장 많이 느낀 감정이 뭐래요?"
    대답: "행복이 아닙니다." (2초 쉬고) "두려움이에요."
    → "한미연이 22,095건을 전수 분석했어요. 오늘 이 데이터로 해부해보겠습니다. 근데 마지막에 반전이 있어요."
  • [해부] 왜 안 하는가 — 약 5분
    📎 한미연 2만건 분석
    돈 53.6% / 감정 조건 ("사랑이 필수 조건") / 행복 9.3% / 두려움
  • [반전] 언제 결심하는가 — 약 5분
    📎 블라인드 "결심하는 순간들"
    "하고 싶은데 모르겠어요" → 34살 과장 11번 취소 → 12번째 성혼 → "편한 사람" 반전
  • [아웃] 몇 살까지 만나야 하는가 — 약 2분 30초
    📎 블라인드 "나이별 소개팅 전략"
    "33살. 급하라는 게 아니라 진지하라는 거예요." 열린 결말.

PD 질문 방식

이번 에피소드는 PD 질문 토크입니다. PD가 질문하면 대표님이 자연스럽게 답하는 형식입니다.

PD 질문은 4가지 패턴만 반복합니다:
"진짜요?" / "그건 좀 불공평하지 않아요?" / "대표님은요?" / "그러면 어떡해요?"

대표님은 아는 만큼, 느끼는 만큼 솔직하게 대답하시면 됩니다.
PD 질문 예시 (이런 느낌으로 진행됩니다)

"9,201명이 가장 많이 느낀 감정이 뭐래요?" — 킥. 숫자 충격.

"결혼이 자격시험이라고요?" — 해부. 돈 문제.

"그동안 가장 많이 들은 말이 뭐예요?" — 본인 경험.

"결정사 데이터에서도 같은 결과요?" — 반전. 크로스 검증.

톤 가이드

이번 에피소드 톤 전환 (4단계)

Q1~Q2: 또박또박 톤 — 숫자 충격. "두려움이에요."

Q3~Q7: 솔직한 톤 — 데이터 해부. 돈/감정/두려움 3단. 현실 직시.

Q8~Q12: 진지 → 따뜻한 톤 — 상담 경험 → "편한 사람" 반전. 미소.

Q13~Q15: 따뜻한 톤 — "33살" + 열린 결말. 희망.
