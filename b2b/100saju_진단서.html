문제 요약 (6가지)
문제 1

100원 결과가 너무 완결적

텍스트로 인생/연애/재물 사주 결과를 전부 보여준다. 답을 다 받았으니 전화할 이유가 없다.

문제 2

가격 갭 780배

100원 → 78,000원. 중간 상품이 없다. 100원 쓴 사람이 바로 78,000원을 쓰지 않는다.

문제 3

전화사주 CTA가 약하다

히어로, 결과 페이지 모두 100원 CTA만 강조. 전화사주는 상품 카드에 조용히 존재할 뿐.

문제 4

실시간 피드가 100원만 보여줌

"김O은님 연애운 구매 방금 전" - 전부 100원. 전화사주 구매 내역이 없어 사회적 증명 부재.

문제 5

"디지털 전화상담" 정체 불명

AI 음성인지 실제 사람인지 불분명. 78,000원 내고 뭘 받는지 모르면 결제하지 않는다.

문제 6

전화 예약 시스템 없음

전화번호(070-)만 표기. 직접 전화 거는 건 심리적 장벽이 높다. 예약형이어야 한다.

해결 방안

02
핵심: 100원은 미끼, 전환 퍼널을 만들어야 한다

현재 구조

  • 100원 결제 → 결과 전체 공개
  • 만족하고 이탈
  • 전화사주는 별도 상품으로 방치
  • 중간 상품 없음
매출 = 100원 x 구매자 수

개선 구조

  • 100원 결제 → 결과 70%만 공개
  • "핵심은 다음 단계에서" → 궁금증 유발
  • 결과 페이지에 전화사주 CTA 삽입
  • 중간 상품으로 계단 설계
매출 = 100원 x N + 중간상품 x N + 78,000원 x N
해결 1: 100원 결과를 70%만 공개
전환율 직접 영향

답을 다 주지 않는다 = 다음 단계로 넘어가는 이유를 만든다

  • 기본 성향, 대운 흐름 등은 공개 (만족감 제공)
  • 핵심 1~2가지를 가린다: "올해 가장 조심해야 할 달은... 프리미엄에서 확인"
  • "당신의 재물운 전환 시기는... 전화상담에서 확인"
  • 가려진 부분이 가장 궁금한 것이어야 전환이 일어남
해결 2: 가격 계단 설계
단계가격상품역할
미끼100원기본 사주 (70% 공개)궁금증 유발, 유입
계단 19,900원상세 리포트 (월별 운세, 궁합 등)결제 습관 형성
계단 229,900원심층 분석 + 채팅 Q&A신뢰 구축
메인78,000원1:1 전화 사주고단가 전환
100원 → 78,000원 (780배 점프)에서, 100원 → 9,900원 → 29,900원 → 78,000원 계단형으로 바꾸면 각 단계 전환율이 올라간다.
해결 3: 결과 페이지에 전화사주 CTA 삽입
즉시 적용 가능

100원 결과 페이지 = 전화사주 전환 페이지로 만든다

  • 결과 텍스트 아래에 "더 깊은 풀이가 필요하신가요?" CTA 배치
  • "박명화 선생이 직접 전화로 알려드립니다" + 예약 버튼
  • 전화사주 후기 2~3개를 결과 페이지에 삽입 (사회적 증명)
  • 현재 이 CTA가 아예 없다 → 넣는 것만으로 전환 발생
해결 4: 전화 "예약" 시스템 도입
행동 장벽 제거

전화번호만 던지지 말고, 예약형으로 바꾼다

  • 현재: "070-8080-2736" 고객센터 표기 → 아무도 안 건다
  • 변경: "예약하면 10분 내 전화드립니다" + 예약 폼
  • 이름, 전화번호, 원하는 시간대만 입력 → 콜백
  • "내가 전화를 건다" vs "전화가 온다"는 전환율이 완전히 다르다

추가 개선 & 실행 우선순위

03
해결 5: 실시간 피드에 전화사주 구매 추가
사회적 증명

현재 피드가 100원 구매만 보여주고 있다

  • 현재: "김O은님 연애운 구매 방금 전" — 전부 100원
  • 변경: "박O수님 전화상담 구매 3분 전" 피드를 섞어 넣는다
  • "다른 사람도 전화상담을 산다" = 전화사주가 정상적인 선택이라는 인식
  • 초기에는 시딩으로 시작, 실제 구매 발생 후 실데이터로 전환
해결 6: "디지털 전화상담" 포지셔닝 명확화
신뢰 확보

78,000원 내고 뭘 받는지 불분명하면 결제하지 않는다

  • "1:1 디지털 전화 상담" — AI 음성? 실제 사람? 헷갈린다
  • AI 음성이면 → "AI가 분석, 전문가가 검수한 결과를 음성으로 전달" 명시
  • 실제 사람이면 → "박명화 선생과 직접 1:1 통화" 명확히 표기
  • 상담 시간, 질문 가능 횟수, 어떤 내용을 다루는지 구체적으로 기재
