계약서 링크

1계약서 열기

위 링크를 크롬 브라우저에서 엽니다.

1페이지에 빈칸이 파란 밑줄로 표시되어 있습니다.

2빈칸 채우기

빈칸을 클릭하면 바로 입력할 수 있습니다.

채워야 할 항목:

  • 전문 — 강사 성명
  • 계약일 — 년 / 월 / 일
  • 계약기간 — 시작일 ~ 종료일
  • 강의주제 — 강의 제목
  • 클래스 분량 — 몇 회
  • 강사 서명란 — 이름, 연락처, 주민번호, 주소, 성함
회사 정보(플로우머스)는 이미 입력되어 있으니 건드리지 않아도 됩니다.

3PDF로 저장

오른쪽 하단 「PDF 저장」 버튼을 클릭하거나, Cmd + P (맥) / Ctrl + P (윈도우)를 누릅니다.

  • 대상: PDF로 저장 선택
  • 여백: 없음 또는 최소
  • 배경 그래픽: 체크
PDF 저장 전에 입력한 내용을 한번 더 확인하세요. 저장 후에는 수정이 안 됩니다. (다시 링크에서 새로 작성하면 됩니다)

4모두사인으로 전송

저장된 PDF를 모두사인에 업로드합니다.

  • 모두사인 접속 → 새 문서 → PDF 업로드
  • 서명 위치 지정: 회사(인) / 강사(인) 위치에 서명 필드 배치
  • 수신자 설정: 강사 이메일 입력 → 전송
모두사인에서 전자서명이 완료되면 양측 모두 서명 완료된 PDF를 받게 됩니다.

5완료 후 보관

서명 완료된 계약서 PDF를 아래 경로에 저장합니다.

  • 공유 드라이브 → 00_Management_Admin → 계약서 폴더
  • 파일명 예시: 부업클래스_강사계약서_홍길동_20260501.pdf
