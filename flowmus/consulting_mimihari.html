인스타 공구 시장이 어려워진 건 대표님 탓이 아닙니다. 시장 구조 자체가 바뀌고 있기 때문입니다.

인스타 정책 변경 한 번에 매출 흔들리는 구조

핵심 문제: 지금 구조는 "인스타가 보여줘야 팔리는" 구조입니다.
내 고객인데, 인스타를 통해서만 연락할 수 있는 상태 — 이게 가장 큰 리스크입니다.

공구를 계속하되, 인스타에 의존하지 않고도 매출을 만들 수 있는 채널을 만드는 것이 핵심입니다. 알고리즘이 아닌 "내 고객 리스트"로 직접 매출을 일으키는 구조로 전환해야 합니다.

02
해결 방향: 3가지 전환
현재 (AS-IS) → 전환 (TO-BE) 기대효과
인스타 알고리즘 의존 → CRM 직접 연락 도달률 100%
단일 채널 매출 → 멀티 채널 매출 매출 소스 분산
일회성 구매 → 반복 구매 구조 고객당 매출 3배↑

03
실행 로드맵 (4단계)
1
고객 DB 구축 + 세그먼트 분류 (1~2주)
기존 구매 고객 데이터를 추출하고, 구매 빈도/금액/카테고리별로 세그먼트를 나눕니다.
→ VIP / 재구매 / 1회 구매 / 이탈 고객으로 분류
→ 각 그룹에 맞는 맞춤 메시지 전략 설계
2
CRM 채널 세팅 — 카톡 + 문자 (1주)
카카오톡 채널 개설 + 알림톡/친구톡 세팅, 문자 발송 시스템 구축.
→ 공구 오픈 시 인스타 없이도 직접 알림 가능
→ 도달률 인스타 10~20% vs 카톡/문자 90%+
3
결제 구조 최적화 — 전용 랜딩페이지 (2주)
공구 전용 랜딩페이지 제작. 상품 설명 + 결제 + 후기가 한 페이지에.
→ DM 주문 → 원클릭 결제로 전환율 2~3배 개선
→ UTM 추적으로 어떤 채널에서 매출이 나오는지 정확히 파악
4
신규 유입 채널 확장 (3~4주)
블로그 SEO, 유튜브 쇼츠, 당근마켓 등으로 신규 고객 유입 경로 구축.
→ 인스타 팔로워 성장 정체해도 매출은 성장하는 구조
→ 검색으로 들어오는 "구매 의도 높은" 고객 확보

핵심 목표: 3개월 후, 인스타 도달률이 0이 되어도 매출의 50% 이상을 유지할 수 있는 구조를 만드는 것.
