현재의 벽
01

소재 발굴 — 창작에서 막힌다

방향성이 주어지면 콘티/대본은 짤 수 있다. 그런데 "뭘 만들지?"를 스스로 찾는 게 가장 어렵다. 트렌드를 따라가는 숏폼이라 유행이 빠르고, 8개월 해봤지만 소재 창작에서 계속 막힌다.

02

성과 판단 — 잘 갔는지 어떻게 아는가?

콘텐츠를 기획하고 편집하고 업로드까지 했다. 그런데 "이게 잘 간 건지, 못 간 건지"를 어떻게 판단하는지 모른다. 데이터를 보는 눈이 없다.

03

매출 연결 — 기획이 돈이 되는 구조를 모른다

현재 매출에 관여하지 않는다. 콘텐츠를 만드는 사람이지, 콘텐츠로 돈을 만드는 사람이 아니다. 기획자가 되려면 이 연결고리를 배워야 한다.

Growth Plan

02
벽을 넘는 3단계
01

소재 발굴 시스템 만들기

"창작"이 아니라 "시스템"으로 바꾼다. 매일 경쟁 계정 3개 분석 → 바이럴 공식 추출 → 우리 컨셉에 맞게 변형. 소재는 만드는 게 아니라 발견하는 것. Flowmus 리서치 시스템 활용.

02

데이터로 콘텐츠 판단하기

업로드 후 24시간/48시간/7일 데이터 체크 루틴. 도달률, 저장률, 공유율 — 이 3개 지표만 보면 된다. "잘 갔는지"는 감이 아니라 숫자로 판단. 주간 리포트 작성으로 눈을 키운다.

03

콘텐츠 → 매출 연결 경험

이세령 다이어트 채널에서 "이 릴스가 공구 매출 OO만원을 만들었다"를 직접 경험. 기획 → 콘텐츠 → 유입 → 구매 전환. 이 퍼널을 한 번 돌려보면 기획자로서 차원이 달라진다.

디자인 출신이 가진 무기

  • 비주얼 감각 — 숏폼은 결국 시각 콘텐츠. 디자인 감각이 곧 경쟁력
  • 레퍼런스 수집력 — 레퍼런스 찾다가 기획으로 왔다 = 이미 리서치 근육이 있다
  • 편집 가능 — 기획 + 편집을 혼자 할 수 있으면 생산성 2배
  • 콘티 감각 — 디자인 → 콘티 → 스토리보드. 자연스러운 확장
Flowmus가 채워주는 것

소재 발굴 시스템

Flowmus 리서치 시스템 (4채널 병렬 조사) → 매일 트렌드/소재 피드 제공. "뭘 만들지?"를 혼자 고민하지 않아도 됨.

데이터 분석 프레임

콘텐츠 성과 대시보드 + 주간 리포트 템플릿 제공. 숫자를 보는 눈을 체계적으로 키운다.

매출 연결 구조

공구/강의/벤더 3개 매출 라인 운영 경험. "콘텐츠가 매출이 되는 순간"을 직접 체험.

성장 피드백 루프

기획 → 제작 → 성과 → 피드백 사이클. 혼자 돌리면 3년, 시스템 안에서 돌리면 3개월.
