Core Structure

01
비즈니스 엔진 — 3개의 축
ENGINE 1

부업클래스 강의

숏폼/롱폼 편집 스킬을 가르치는 강의. 수강생이 곧 편집자 인력풀이 된다.

ENGINE 2

편집 대행 사업

수강생 + 크몽/편집몬 편집자를 흡수. 숏폼·롱폼 편집 대행 라인 구축.

ENGINE 3

대행사 레버리지

기존 숏폼 대행사와 제휴. 레퍼런스를 가져오고, 매출을 나누는 구조.

핵심 — 강의가 인력 파이프라인이고, 대행이 매출 엔진이다

  • 강의 수강생이 바로 편집자 인력풀 → 채용 비용 0원
  • 편집자가 실전 수주하면 수강생 실제 수익 발생 → 강의 신뢰도 상승
  • 대행 레퍼런스가 쌓이면 더 큰 클라이언트 유입 → 매출 자동 확장
  • 이 사이클이 돌면 → 유튜브 편집 시장 1등
머니몬스터 포지션

얼굴 마담 + 강사

유튜브 수익화/편집 분야의 대표 얼굴. 부업클래스 메인 강사. 대행사 미팅에서 레퍼런스 확보의 핵심 인물.

현재 자산

월 매출 2,000만원 강의 경험. 유튜브 수익화 실전 노하우. 5/25 사이클클래스 강의 확정. 강사로서의 검증된 트랙레코드.

Agency Model

02
편집 대행 — 4개 라인
LINE 1

숏폼 제작 대행

릴스/쇼츠/틱톡 숏폼 대량 제작. 소상공인·인플루언서 대상. 건당 5~15만원.

LINE 2

롱폼 편집 대행

유튜브 본편 영상 편집. 유튜버·기업 대상. 편당 15~40만원.

LINE 3

크몽 대행

크몽 플랫폼 내 편집 서비스 운영. 수강생을 크몽 전문가로 세팅, 수주 지원.

LINE 4

당근 대행

당근마켓 소상공인 대상 숏폼 광고/콘텐츠 제작 대행. 지역 밀착형 영업.

편집자 수급 전략

부업클래스 수강생

강의 수료 → 실전 편집 테스트 → 합격 시 대행 풀 투입. 비용 0원으로 인력 확보.

크몽/편집몬 편집자

기존 프리랜서에게 출연 제안 + 안정적 일거리 제공 조건으로 계약. 즉시 투입 가능.

대행사 제휴

기존 숏폼 대행사와 매출 쉐어. 머니몬스터/사찍남이 얼굴 마담, 레퍼런스 독점 확보.

매출 시뮬레이션
수익 라인 단가 월 건수 월 매출
부업클래스 강의 285만원 35~70명/기 1~2억/기
숏폼 대행 10만원 100건 1,000만원
롱폼 편집 대행 25만원 40건 1,000만원
크몽/당근 대행 10만원 50건 500만원
월 대행 매출 (강의 제외) 2,500만원

출판 — 플로우북스

유튜브 편집으로 월 500만원 버는 현실 부업

강의 1기 수강생 실제 수익 사례 + 머니몬스터 노하우를 책으로. "이 강사는 책도 낸 사람이다" → 강의 전환율 상승. 대행 사업의 신뢰 자산.

강의 → 대행 → 출판 = 하나의 IP
