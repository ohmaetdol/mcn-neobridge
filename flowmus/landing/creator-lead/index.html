Solution

구조를 바꾸면 됩니다

내 영상 → 내 랜딩 → 내 DB → 그 다음 플랫폼

BEFORE
내 영상 → 플랫폼 링크
고객 정보 → 플랫폼 DB
정산 → 플랫폼이 알려주는 숫자
DB 주권 = 플랫폼
AFTER
내 영상 → 내 랜딩페이지
고객 정보 → 내 구글시트
자동 이동 → 플랫폼 오픈채팅
DB 주권 = 나
