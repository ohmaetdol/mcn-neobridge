시장 구조

1단계 — 체험단 플랫폼 (매칭 중개)

포지셔닝 기회

  • 푸드 전문 대행사 중 "크리에이터 출신"이 운영하는 곳은 아직 없음
  • 60만 팔로워 + 실전 경험 = 클라이언트 신뢰의 최강 무기
  • "내가 직접 해봤으니까 아는" 포지셔닝은 일반 대행사가 가질 수 없는 차별점

조직 설계 가이드
대행사의 전형적 조직 구성과, 지금 상황에 맞는 최소 구조입니다.

대행사 표준 조직 (성장 후)

대표
콘텐츠 방향 + 핵심 클라이언트 관리
|
AE (영업)
클라이언트 소통, 계약, 일정 관리
마케터
캠페인 기획, 인플루언서 섭외, 성과 분석
콘텐츠 제작
촬영, 편집, 디자인, 상세페이지
편집/디자인 외주
건당 계약, 필요시 정규직 전환

지금 바로 시작할 수 있는 최소 구조 (3명)

대표 (온서)
콘텐츠 제작 + 브랜딩 + 핵심 클라이언트
|
매니저 1명 (신규 채용)
클라이언트 소통, 스케줄 관리, CS — 대표의 약점 보완
편집자 (외주)
건당 5~10만원, 볼륨 늘면 정규직 전환

친구와 일할 때 규칙

1. 계약서 필수 — 친구여도 업무 범위, 보수, 종료 조건 명시
2. R&R 문서화 — "네가 할 일"과 "내가 할 일"을 명확히 분리
3. 피드백 구조 — 감정이 아닌 기준으로 이야기할 수 있는 체크리스트
4. 정기 리뷰 — 월 1회 서로의 기대치 확인 미팅

규칙이 없으면 관계가 무너진다. 규칙이 있으면 관계가 오래 간다.

ROADMAP
대행사 시작 로드맵
지금 상황에서 바로 실행할 수 있는 단계별 계획입니다.

1 기반 정리

지금 ~ 2주
  • 조교(친구)와 R&R 문서화 + 계약서 작성
  • 현재 하고 있는 업무 전체 리스트업 (SOP 초안)
  • 대행사 서비스 메뉴 확정 (촬영? 광고? 컨설팅?)

2 첫 번째 채용

1개월
  • AE/매니저 1명 채용 (클라이언트 소통 담당)
  • 파트타임 or 인턴으로 시작 → 검증 후 정규직
  • 대표가 외부 소통 부담에서 벗어나는 구조 만들기

3 클라이언트 확보

1~3개월
  • 기존 협찬/광고 관계에서 대행 전환 (3~5개)
  • 포트폴리오 정리 — 본인 채널 성과가 최고의 영업 자료
  • 타이탄 클래스 수강생 중 잠재 클라이언트 발굴

4 시스템 구축

3~6개월
  • 편집자 추가 (외주 → 볼륨 늘면 정규직)
  • 클라이언트 관리 프로세스 매뉴얼화
  • 대표 없이도 돌아가는 구조 완성

기억할 것

  • 공존마케팅도 처음부터 26명이 아니었다 — 3명으로 시작해서 20억
  • 첫 직원은 대표의 약점을 채우는 사람을 뽑아야 한다
  • 직원 관리가 어려우면 "기준"을 만들면 된다 — 감정이 아닌 시스템으로
  • 60만 팔로워 + 실전 경험 = 어떤 대행사도 못 가진 자산

크리에이터에서 대행사로 가는 길은
이미 성공한 사람만이 걸을 수 있는 길입니다.
지금 가진 자산을 구조화하면, 분명 됩니다.
