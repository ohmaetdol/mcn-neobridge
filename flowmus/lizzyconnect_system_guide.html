"돈이 들어오면 돈이 새는" 5가지 원인

1. 정산 관리 부재 — 입금/출금 내역을 체계적으로 추적하지 않음

2. 인플루언서 비용 산정 불투명 — 건마다 다른 단가, 기준 없는 지급

3. 세금/원천징수 누락 — 현찰 거래 시 세무 리스크 축적

4. 본인 생활비 미분리 — 사업 계좌 = 개인 계좌 혼용

5. 수익률 미측정 — 매출은 아는데 순이익을 모름

매출 1억을 해도 남는 게 없으면 의미가 없다.
새는 구멍부터 막아야 한다.

03
FIX

돈이 새는 구멍 막기

지금 당장 할 수 있는 5가지

1. 사업용 통장 분리

가장 먼저, 오늘 바로

  • 사업용 통장 1개 (입금 전용)
  • 비용 지출 통장 1개 (인플루언서 정산용)
  • 개인 통장과 완전 분리
  • 카드도 사업용/개인용 분리

2. 건별 정산표 만들기

모든 건에 대해 한 줄씩 기록

  • 브랜드명 / 캠페인명
  • 총 수주 금액
  • 인플루언서 지급 총액
  • 기타 비용 (촬영, 제작 등)
  • 순이익 = 수주 - 지급 - 비용

3. 인플루언서 단가 기준표

매번 감으로 주지 않기

팔로워 피드 1건 릴스 1건
1K~5K5~10만10~20만
5K~30K15~30만30~50만
30K~100K50~100만80~150만
100K+협의협의

기준이 있어야 마진율을 예측할 수 있다

4. 세무 구조 정리

현찰 거래 = 세무 리스크

  • 인플루언서 지급 시 3.3% 원천징수
  • 세금계산서 or 현금영수증 발행
  • 분기별 부가세 신고
  • 세무사 월 기장 계약 (월 10~15만)

5. 마진율 목표 설정

수주 금액의 최소 30~40%는 남겨야 한다

예) 잭다니엘 5,000만원 건 → 인플루언서 비용 3,000만 → 기타 비용 500만 → 순이익 1,500만 (30%)

마진율이 20% 이하로 떨어지면 해당 건은 적자 가능성 — 수주 전에 계산하는 습관 필요

수작업에서 시스템으로

리지커넥트를 버릴 수 없다면, 구조화해야 한다

리지커넥트의 강점은 분명하다: 인플루언서 네트워크를 직접 갖고 있고, 대형 건을 수주할 수 있다. 문제는 이 과정이 전부 세령 대표님의 머릿속에서만 돌아간다는 것.

최소 시스템 — Google Sheet 3개로 시작

Sheet 1: 캠페인 관리

  • 브랜드명 / 캠페인명 / 수주 금액
  • 진행 상태 (제안 → 계약 → 진행 → 정산)
  • 배정 인플루언서 / 지급액
  • 마진율 자동 계산

Sheet 2: 인플루언서 DB

  • 이름 / 계정 / 팔로워 / 카테고리

  • 과거 캠페인 이력 + 성과
  • 연락처 / 정산 계좌

Sheet 3: 월별 손익

  • 월 총 수주액 / 인플루언서 지급 총액 / 기타 비용 / 순이익

ACTION

당장 실행 체크리스트

이번 주 안에 끝낼 수 있는 것들

이번 주 (즉시)

  • 사업용 통장 개설 — 입금용 + 지출용 분리. 개인 계좌 혼용 즉시 중단
  • 지금까지 진행한 건 정리 — 잭다니엘 2건 + 5천만 건 포함, 수주/지급/순이익 한 줄씩
  • 세무사 계약 — 월 기장 (10~15만원). 현찰 거래 정리 + 원천징수 세팅

이번 달 (5월 중)

  • 인플루언서 단가 기준표 — 팔로워 구간별 피드/릴스/스토리 단가 확정
  • Google Sheet 3개 세팅 — 캠페인 관리 / 인플루언서 DB / 월별 손익
  • 마진율 최소 기준 — 30% 이하 건은 받지 않는 기준 설정

다음 달 (6월)

  • 캠페인 리포트 템플릿 — 브랜드에게 결과 보고 → 재수주율 증가
  • 인력 1명 — 매칭/정산/리포트 담당 파트타임 (월 100~150만)
  • 프로세스 매뉴얼 — 수주→매칭→진행→정산 4단계 SOP
