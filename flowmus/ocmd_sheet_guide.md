## 타임라인 탭 — 사용법

**가장 중요한 탭입니다. 여기서 전체 진행 상황을 관리합니다.**

### 열 구조

| 열 | 내용 | 입력 방식 |
|----|------|----------|
| A (주차) | P0-W1, P1-W2 등 | 자유 입력 |
| B (일자) | 5/17, 5/18 등 | 직접 수정 |
| C (핵심 업무) | 할 일 | 직접 입력 |
| D (산출물) | 결과물 | 직접 입력 |
| E (담당) | 담당자 | **드롭다운** 선택 |
| F (상태) | 진행 상황 | **드롭다운** 선택 |
| G (비고) | 메모 | 자유 입력 |

### 드롭다운 옵션

**담당 (E열):**
- 오맷돌 / 권현우 / 오은환 대표 / 오현진 이사 / 전원

**상태 (F열):**
- 대기 → 진행중 → 완료
- 지연 (기한 넘긴 것)
- 보류 (일단 멈춤)

### 하고 싶은 것별 방법

| 하고 싶은 것 | 방법 |
|-------------|------|
| **업무 추가** | 해당 Phase 안에서 우클릭 → "아래에 행 삽입" → A~G 채우기 |
| **날짜 변경** | B열 날짜만 수정 |
| **담당 변경** | E열 클릭 → 드롭다운에서 선택 |
| **상태 변경** | F열 클릭 → 드롭다운에서 선택 |
| **업무 삭제** | 행 선택 → 우클릭 → "행 삭제" |
| **메모 추가** | G열에 자유롭게 입력 |

### 건들지 말 것

```
▶ Phase 0: 준비 (5/17~20) — 계약 + 세팅     ← 이 행은 수정 X
▶ Phase 1: 재수강 클로즈드 (5/21~28)          ← 이 행은 수정 X
```

`▶`로 시작하는 Phase 구분행은 **대시보드가 Phase를 인식하는 기준**이라 수정하면 안 됩니다.

## 나머지 탭 — 공통 규칙

모든 탭은 같은 구조입니다:

```
◼ 섹션 제목          ← 수정 X (진한 배경)
헤더행               ← 수정 X (네이비 배경)
데이터행             ← 자유롭게 수정/추가/삭제
데이터행
(빈 행)
◼ 다음 섹션 제목     ← 수정 X
헤더행               ← 수정 X
데이터행             ← 자유롭게 수정
```

**규칙 요약:**
- `◼`로 시작하는 행 = 섹션 제목 → 수정 X
- 바로 아래 네이비 배경 행 = 헤더 → 수정 X
- 그 아래 데이터행 = **자유롭게 수정·추가·삭제 가능**

## 대시보드 사용법

1. 시트에서 **상태를 변경**합니다 (대기 → 진행중 → 완료)
2. 대시보드를 열고 **새로고침** 버튼을 누릅니다
3. 진행률 바, 요약 카드, Phase별 상태가 **자동 계산**됩니다

대시보드에 표시되는 것:
- 전체 진행률 (%)
- 완료 / 진행중 / 대기 / 지연 개수
- Phase별 진행률 바
- 담당자별 색상 태그

## 일일 업무 흐름

```
아침  →  시트 열기 → 오늘 할 일 확인 → 상태를 "진행중"으로 변경
작업  →  업무 진행
완료  →  상태를 "완료"로 변경 → 비고에 메모 (필요시)
저녁  →  오맷돌이 일일 리포트 작성 → 단톡방 공유
```
