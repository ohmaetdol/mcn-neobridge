인입 — 어디서 찾는가

  • DM 아웃바운드: 팔로워 1K~50K 크리에이터 직접 연락
  • 클래스/강의: 유튜브 클래스 수강생 중 유망주 발굴
  • 소개 보상: 기존 크리에이터가 신규 추천 시 인센티브
  • 콘텐츠 마케팅: "우리와 함께 하면" 성장 사례 공개

선별 — 누구와 하는가

  • 의지 > 팔로워 수: 꾸준히 올리는 사람이 성공
  • 체크리스트: 주 2회 이상 업로드 가능? 피드백 수용? 장기적 목표?
  • 1주 테스트: 과제 1개 → 기한 내 제출 여부로 판단
  • 계약 전 시범기간: 2주~1개월 무계약 협업

온보딩 — 첫 30일

  • Week 1: 채널 분석 + 포지셔닝 확정
  • Week 2: 콘텐츠 3개 기획 + 촬영 가이드
  • Week 3: 첫 영상 업로드 + 피드백
  • Week 4: 루틴 세팅 + 주간 리포트 시작

유지 — 왜 떠나지 않는가

  • 수익: 투명한 정산 + 성장에 따른 수익 증가
  • 성장: 월간 채널 리뷰 + 트렌드 브리핑
  • 소속감: 월 1회 크리에이터 모임, 단톡방
  • 비전: 개인 브랜드 확장 지원 (강의, 커머스)

핵심 지표 (KPI)

인입: 월 신규 접촉 수  |  선별: 계약 전환율  |  온보딩: 30일 내 첫 업로드 비율  |  유지: 6개월 잔존율

PD ROLE

PD 역할 재정의

"편집자"가 아닌 "크리에이터 파트너"로

채널을 같이 키우자 (X)
사람을 모으는 시스템을 같이 만들자 (O)

기존 PD vs 파트너 PD

영역 기존 PD (편집 중심) 파트너 PD (시스템 중심)
콘텐츠 의뢰받은 영상 편집 기획 참여 + 편집 + 성과 분석
크리에이터 관여 없음 담당 크리에이터 코칭 + 관리
발굴 관여 없음 신규 크리에이터 발굴 + 온보딩
보상 건당 고정비 발굴한 크리에이터 매출의 %
성장경로 프리랜서 유지 팀 리더 / 사업부장 가능

PD당 운영 구조

3~5명

PD당 담당 크리에이터

3명 이하: PD 역량 낭비

5명 초과: 관리 품질 저하

최적: 3명으로 시작 → 안정 후 5명

2단계

보상 구조

Phase 1 (0~3개월): 월 고정비 + 성과 보너스

Phase 2 (4개월~): 레브쉐어 전환, 담당 채널 매출의 15~25%

PD에게 주는 것

  • 포트폴리오 — 본인이 키운 채널 = 본인의 실적. 이직/독립 시에도 자산
  • 시스템 — 기획 템플릿, 편집 가이드, 분석 도구 제공. 혼자보다 빠르게 성장
  • 네트워크 — 크리에이터, 브랜드, 다른 PD와의 연결. 프리랜서로는 못 만드는 인맥
  • 수익 다각화 — 편집비 + 채널 수익 + 발굴 인센티브. 단일 수입원 탈출

ROADMAP

실행 로드맵

플랜 단계에서 매출 단계까지

Month 1~2 | 셋업

파트너 PD 온보딩 + 첫 크리에이터 확보

PD와 협력 계약 체결 (하이브리드 모델) / PD당 크리에이터 1~2명 매칭 / 기획-촬영-편집 워크플로우 1회 완주

Month 3~4 | 검증

시스템 테스트 + 첫 매출

PD당 크리에이터 3명 운영 / 첫 광고 매출 또는 브랜디드 콘텐츠 수주 / 온보딩 프로세스 표준화 완료

Month 5~6 | 확장

크리에이터 파이프라인 가동

월 신규 크리에이터 3~5명 인입 / 레브쉐어 전환 시작 / PD 추가 영입 검토 (3명째)

Month 7~12 | 성장

매출 안정화 + 조직화

PD 3명 x 크리에이터 5명 = 15명 운영 체제 / 월 매출 목표 도달 / 정규직 전환 또는 사업부 분리 검토

# 질문 선택지
1 PD당 담당 크리에이터 수 3명 (집중형) vs 5명 (확장형)

3 크리에이터 모집 주체 회사 주도 vs PD 자율 발굴 vs 공동
