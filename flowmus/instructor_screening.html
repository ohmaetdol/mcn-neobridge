Meeting Structure

01
모든 강사 미팅은 동일한 질문, 동일한 순서, 동일한 시간으로 진행합니다.
30분 안에 끝내는 것이 원칙이며, 추가 논의가 필요하면 2차 미팅을 잡습니다. 최대 1시간을 넘기지 않습니다.
30분 타임라인
0:00
오프닝 (2분)

인사 + 미팅 목적 안내: "30분간 상호 평가를 위한 미팅입니다. 강의 주제의 상품성과 협업 가능성을 함께 확인하겠습니다."

2:00
BLOCK A. 전문성 검증 (7분)

강사의 실전 경험, 차별점, 기존 활동 이력 확인

9:00
BLOCK B. 오디언스 검증 (5분)

기존 팔로워, 판매 이력, 모객 가능성 확인

14:00
BLOCK C. 상품성 분석 (8분)

강의 주제의 시장 수요, 경쟁 현황, 변화 약속(Before/After) 확인. 가장 중요한 블록

22:00
BLOCK D. 제작 & 의지 (5분)

제작 가능 일정, 기존 콘텐츠 유무, 기대사항 확인

27:00
클로징 (3분)

스코어카드 기반 판정 → 3가지 중 하나: 계약 제안 / 보완 후 재미팅 / 정중한 거절

30분 초과 시: "오늘 말씀 감사합니다. 추가로 논의할 내용이 있어서 2차 미팅을 잡겠습니다."로 자연스럽게 마무리합니다. 절대 1시간을 넘기지 않습니다.
미팅 전 준비물
강사 소셜미디어 사전 조사 (팔로워 수, 콘텐츠 주제, 참여도)
해당 주제 경쟁 강의 3개 사전 조사 (클래스101, 인프런, 탈잉 등)
해당 주제 검색량 확인 (네이버 키워드, 구글 트렌드)
스코어카드 출력 (이 매뉴얼 4페이지)
강사 제휴 계약서 링크 준비

Standard Questions

02
BLOCK A. 전문성 검증 7분
1
이 분야에서 가장 자랑스러운 성과 하나만 말씀해 주세요. 평가: 구체적 숫자/사례가 나오는지 (매출, 고객 수, 수강생 후기 등)
2
이 일을 몇 년 하셨고, 가장 어려웠던 프로젝트는 무엇이었나요? 평가: 실전 경험의 깊이. 3년 미만이면 추가 검증 필요
3
이 분야에서 사람들이 가장 많이 하는 실수는 뭔가요? 본인만 아는 노하우가 있다면? 평가: 차별화 포인트 = 강의 소구점. 뻔한 답이면 위험 신호
4
소득증명이 가능한 자료가 있으신가요? (매출 내역, 포트폴리오, 고객 후기 등) 평가: 증빙 가능한 실적이 있어야 강의 신뢰도 확보. 없으면 보완 필요
5
이전에 강의/교육 경험이 있으신가요? (유튜브, 블로그, 워크숍, 코칭 등 모든 형태) 평가: 교육 경험 유무. 없어도 OK이지만 제작 리스크 상승
BLOCK B. 오디언스 검증 5분
6
이 강의를 들을 사람은 정확히 누구인가요? (나이, 직업, 현재 겪는 문제) 평가: 타겟이 명확할수록 마케팅 효율 높음. "누구나"는 위험 신호
7
현재 이 주제로 팔로잉하는 사람이 있나요? (소셜, 이메일, 커뮤니티, 기존 고객) 평가: 최소 500명 이상의 팔로워 = 런칭 부스터. 0명이면 마케팅 전액 회사 부담
8
이 주제로 돈을 받고 판매해본 경험이 있나요? (제품, 서비스, 코칭, 전자책 등) 평가: 유료 판매 경험 = 시장 검증 완료. 무료만 해봤다면 전환율 미검증
9
지금 바로 강의 오픈한다면 48시간 안에 몇 명에게 알릴 수 있나요? 평가: 즉시 도달 가능한 모수. 50명 이상이면 양호, 200명 이상이면 우수
핵심: BLOCK A는 "이 사람이 진짜인가?", BLOCK B는 "이 사람이 모을 수 있는가?"를 검증합니다. 둘 다 약하면 계약을 보류합니다.

Standard Questions

03
BLOCK C. 상품성 분석 (가장 중요) 8분
10
수강생이 이 강의를 검색한다면 어떤 키워드로 검색할까요? 평가: 사전 조사한 검색량과 대조. 월 1,000회 미만이면 니치, 10,000회 이상이면 수요 확인
11
이 주제로 가장 잘 팔리는 강의를 아시나요? 그 강의와 본인의 차이점은? 평가: 경쟁사 인지 여부 + 차별화 포인트. 경쟁 강의가 0개면 수요 미검증 위험
12
수강 전과 후를 한 문장으로 말씀해 주세요.
"수강 전에는 ___ 하지만, 수강 후에는 ___일 안에 ___ 할 수 있다" 평가: 변화가 구체적이고 측정 가능할수록 상품성 높음. "배운다"는 약함, "월 100만원 번다"는 강함
13
이 변화를 실제로 경험한 사람(수강생, 고객, 제자)이 있나요? 증거가 있나요? 평가: 후기/사례 3건 이상 = 상품 검증 완료. 본인 경험만 있으면 재현성 미검증
14
수강생 입장에서 이 강의가 본전을 뽑을 수 있는 구조인가요? (수익, 이직, 비용 절감 등) 평가: ROI가 명확한 강의는 가격 저항이 낮음. 취미형은 가격 천장이 낮음
BLOCK D. 제작 의지 & 실행력 5분
15
강의 형태는 어떻게 생각하시나요? (대면, 온라인, 녹화, 라이브, 하이브리드) 평가: 우리 프로덕션 구조와 맞는지 확인
16
현재 일정 기준, 강의 제작을 언제까지 완료할 수 있나요? 평가: 비현실적 답변(1주일) 또는 너무 긴 답변(6개월+)은 위험 신호
17
기존에 촬영한 영상 콘텐츠가 있나요? (유튜브, 릴스, 웨비나 등) 평가: 기존 영상이 있으면 카메라 적응 완료 = 제작 리스크 낮음
18
정산 구조, 마케팅 지원 등에 대한 기대사항이 있으시면 말씀해 주세요. 평가: 기대치 정렬. 비현실적 기대(90:10 등)는 초기에 조율 필요
절대 하지 않는 것: 강사마다 다른 질문을 즉흥으로 하지 않습니다. 18개 질문은 모든 강사에게 동일하게 적용합니다. 추가 질문은 2차 미팅에서 합니다.

Scorecard

04
미팅 직후 작성합니다. 각 항목 1~5점. 합산 점수로 Go/No-Go를 판정합니다. 감이 아닌 데이터로 결정합니다.
평가 항목 점수
1. 검색 수요 1점: 검색량 없음 / 3점: 월 1,000~10,000 / 5점: 월 10,000+ (네이버/구글) /5
2. 경쟁 환경 1점: 경쟁 강의 0개(수요 미검증) / 3점: 3~5개 존재 / 5점: 다수 존재 + 빈틈 확인 /5
3. 변화의 구체성 1점: "배운다" 수준 / 3점: 구체적 스킬 / 5점: 측정 가능한 성과 + 기한 ("30일 내 월 100만원") /5
4. 강사 권위 1점: 경력 없음 / 2점: 500명 미만 / 3점: 500~5,000명 OR 자격증 / 4점: 5,000~20,000명 / 5점: 20,000명+ OR 유료 교육 이력 /5
5. 자체 오디언스 1점: 0명 / 2점: 100~500명 / 3점: 500~2,000명 / 4점: 2,000~10,000명 / 5점: 10,000명+ /5
6. 가격 결정력 1점: 무료로만 가능 / 3점: 3~10만원대 / 5점: 15만원+ 가능 (ROI 명확) /5
7. 차별화 1점: 기존과 동일 / 3점: 부분 차별화 (포맷, 난이도) / 5점: 시장 공백 확인 /5
8. 성과 재현성 1점: 본인 경험만 / 3점: 5~20명 비공식 교육 / 5점: 20명+ 문서화된 성과 /5
9. 제작 준비도 1점: 콘텐츠 0 / 3점: 유튜브/블로그 있음 / 5점: 커리큘럼 + 샘플 영상 준비 완료 /5
10. 실행 의지 1점: 모호함 / 3점: 60~90일 타임라인 + 자체 홍보 의향 / 5점: 즉시 착수 가능 + 런칭 계획 구체적 /5

미팅 후 필수 수집 서류
소득증명 자료 — 매출 내역, 수익 스크린샷, 사업자 매출 증빙 등 (강의 신뢰도의 핵심)
포트폴리오 — 소셜미디어 프로필, 기존 콘텐츠, 고객 사례 링크
수강생/고객 후기 — 최소 3건 (DM 캡처, 리뷰, 후기 등)
커리큘럼 초안 — 최소 4개 모듈, 각 모듈별 학습 목표
샘플 영상 — 2~3분 분량, 기존 촬영분 가능 (카메라 적응도 평가용)
서류는 미팅 당일 또는 7일 이내 제출을 요청합니다. 7일 내 미제출 시 우선순위를 하향 조정합니다.

Post-Meeting Process

05
미팅 후 48시간 내 처리
판정 액션
즉시 계약
(40~50점)		 1. 당일: 감사 메시지 + 계약서 링크 전송
2. 3일 내: 모두사인 전자서명 진행
3. 서명 완료 후: 단톡방 개설 + 플레이북 공유 + 주간 일정 확정
조건부 계약
(30~39점)		 1. 당일: 감사 메시지 + 보완 요청사항 2가지 구체적으로 안내
2. 7일 내: 보완 자료 수령
3. 수령 후: 스코어카드 재채점 → 30점 이상이면 계약 진행
보류
(20~29점)		 1. 당일: 감사 메시지 + "추가 준비 후 다시 뵙겠습니다"
2. 구체적 보완사항 리스트 전달
3. 1개월 후 팔로업 연락
거절
(~19점)		 1. 당일: 정중한 감사 메시지
2. "현재 시점에서는 어렵지만, 준비되시면 언제든 연락 주세요"
3. 연락처 보관 (향후 재접촉 가능)
강사 데이터 기록
모든 미팅 결과는 동일한 양식으로 기록합니다. 감에 의한 판단이 아닌, 축적된 데이터로 강사 선발 기준을 지속적으로 개선합니다.
