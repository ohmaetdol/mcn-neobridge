STRENGTHS · 대표님만의 강점
자체 공장 = MOQ 0 — 일반 공장은 300~500장 최소 주문. 대표님 공장은 1장부터 제작 가능. 수강생 진입 장벽이 극적으로 낮아짐.
100만원으로 자기 브랜드 — 샘플 5개 기준 100만원이면 시작 가능. 어떤 창업 강의보다 진입 비용이 낮음.
토미토 매출 증명 — 광고비 없이 하루 1,000만원+. "사진이 이쁘면 어머님들이 알아서 해준다"는 걸 직접 증명.
12년 경력 + 6년 교육 — 원단 수배부터 판매까지 전 과정을 한 분이 가르칠 수 있는 건 시장에 거의 없음.
아동복 = 틈새 시장 — 성인복 대비 경쟁이 1/10. "제이하다가 가장 유명하다"는 수강생들의 직접 평가.

REQUEST · 준비해 주실 자료
갖고 계신 자료는 최대한 많이 보내주시는 게 좋습니다. 증빙 자료가 많을수록 강의 신뢰도가 올라가고, 마케팅 소재로 활용할 수 있는 것도 많아집니다.
  • 토미토 매출 데이터
    카페24 관리자 매출 대시보드 캡처. 일별/주별. 하루 1,000만원+ 확인용. 외부 공개 X, 내부 검증용.
  • 교육 입금내역 (최근 3개월)
    통장 사본 or 모바일뱅킹 캡처. 교육비 수취 확인용. 계좌번호 가려주셔도 됩니다.
  • 수강생 성공 사례 (최소 5건)
    매출 캡처 + 제작 비포/애프터 + 텍스트 후기. 카톡 캡처도 OK. "일주일 4,000만원" 같은 사례 포함.
  • 공장 사진/영상
    제이하다 공장 현장. 봉제 과정, 재단 과정, 완제품 등. 촬영 때 추가로 찍겠지만 기존 자료도 보내주세요.
  • 토미토 제작 과정 사진/영상
    원단 → 디자인 → 샘플 → 완제품 → 촬영 → 판매. 비포/애프터. 컨셉 기획 과정 포함.
  • 기존 교육 자료 전체
    원단 이론 수업 자료, 봉제 이론 자료, 디자인 구성 예시, 도시카 샘플 등. 있는 대로 다 보내주세요.
  • 교육생 제작 포트폴리오
    교육생분들이 만든 옷 사진. 다양한 디자인/스타일. 강의 결과물 보여주기용.
  • 사업자등록증 사본
    제이하다 사업자등록증. 공장 사업자 포함.
위 리스트 외에도 교육하시면서 쌓인 자료가 있다면 뭐든 보내주세요. 카톡 대화, 수강생 작업 과정 사진, 원단 시장 사진, 완제품 사진 등 — 많을수록 좋습니다.
WE DO · 저희가 준비할 것
유튜브 채널 출연 기획 — 2~3개 채널 기획서 작성 후 선택지 드리겠습니다. 공장 현장 촬영 포함.

결제/CS 시스템 — 결제 시스템, 웨비나, CS 안내 등은 현우 대표님이 세팅해 드립니다.
